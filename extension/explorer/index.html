Your discovery workspace

Import a JSON export from the w3bm@p CLI, Extension, or PHP Connector. Select or drop multiple files to combine them into a single comprehensive investigation without duplicate entities or relationships.

  1. Use the filters and search to narrow the graph.
  2. Select an entity or relationship to inspect evidence.
  3. Use Tree view to browse pages and findings as folders.
  4. Use the Entities tab for keyboard navigation.
  5. Use Merge reports to combine additional findings into the active view.
  6. Open Collection to inspect module results and errors.
  7. Export JSON to save the complete, original collection.

Imports replace the current collection unless you choose Merge reports. Filters never remove data from your export. Data stays in memory and is cleared when you reload. The initial sample is synthetic.

Limits: 16 MiB · 5,000 entities · 15,000 relationships. Chrome extension and direct connector queries are planned.
